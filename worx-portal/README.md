# ECU Mems Manager

Alpha2 base.

## Worx Equipe Frontend Portal

A frontend portal is available at:

`/home/runner/work/ECU-Mems-Manager/ECU-Mems-Manager/worx-portal`

### Run locally

```bash
cd /home/runner/work/ECU-Mems-Manager/ECU-Mems-Manager/worx-portal
npm install
npm run dev
```

Open `http://localhost:3000`.

### Features

- Manage Worx Equipe bot model assignments in a single dashboard.
- Connect and validate Notion integration from the portal.
- Connect and validate ChatGPT (OpenAI) integration from the portal.
